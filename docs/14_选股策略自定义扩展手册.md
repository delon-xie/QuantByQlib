# 14 — 选股策略自定义扩展手册

> 本文档说明如何将传统技术指标策略（如 MA10 抬头、双均线金叉、MACD 背离等）集成到量化选股页面 `screening_page.py`，与现有 5 种 Qlib ML 策略并列运行。

---

## 1. 架构全景

```
screening_page.py  ──emit──▶  run_requested(strategy_key, instrument)
       │
       ▼
stock_screener.py  ──call──▶  get_strategy(key) → strategy.run(universe, cb)
       │                              │
       ▼                              ▼
  StrategyResult              strategies/qlib_strategy.py
  (统一输出格式)              STRATEGY_REGISTRY (注册表)
```

**关键契约**：无论策略内部是 Qlib ML 模型还是传统技术指标，只要实现了 `BaseStrategy.run()` 并返回 `StrategyResult`，就能无缝接入选股流程。

---

## 2. 核心接口：`BaseStrategy`

文件：`strategies/base_strategy.py`

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
import pandas as pd

@dataclass
class StrategyResult:
    strategy_key:  str          # 策略标识 (如 "ma10_turnup")
    strategy_name: str          # 显示名称 (如 "MA10抬头策略")
    scores:        pd.Series    # index=ticker, value=预测分数 (降序)
    topk_tickers:  list[str]    # 最终选出的 Top-K 股票
    model_name:    str          # 模型名称 (如 "MA10 Turn-Up")
    universe_size: int          # 参与筛选的股票总数

class BaseStrategy(ABC):
    KEY:  str = ""              # 子类必须定义
    NAME: str = ""              # 子类必须定义
    TOPK: int = 50              # 默认选出数量

    @abstractmethod
    def run(self, universe: list[str], progress_cb=None) -> StrategyResult:
        ...
```

**唯一必须实现的方法**：`run(universe, progress_cb)`，它接收候选股票列表，返回 `StrategyResult`。

## 3. 三步集成流程

### 第一步：编写策略类

在 `strategies/screening/` 下创建策略文件（如 `ma10_screening.py`），关键点：

| 要点 | 说明 |
|------|------|
| **继承** | 必须继承 `strategies.base_strategy.BaseStrategy` |
| **定义 KEY** | 唯一标识符，用于注册表和 UI 卡片匹配 |
| **定义 NAME** | 中文显示名称 |
| **实现 run()** | 核心逻辑：获取数据 → 计算指标 → 打分排序 → 返回结果 |
| **progress_cb** | 回调 `(pct: int, msg: str)` 更新 UI 进度条 |
| **scores** | 必须返回 `pd.Series`，index 为大写 ticker，value 为分数（越高越好） |

**MA10 抬头策略完整示例**（`strategies/screening/ma10_screening.py`）：

```python
from strategies.base_strategy import BaseStrategy, StrategyResult
import pandas as pd
import numpy as np
from loguru import logger

class MA10TurnUpScreenStrategy(BaseStrategy):
    """MA10抬头选股策略 —— 筛选 10 日均线拐头向上的股票"""

    KEY = "ma10_turnup"
    NAME = "MA10抬头策略"
    TOPK = 20

    def __init__(self, 
                 topk: int = None,
                 require_vol_confirm: bool = False,
                 require_price_above_ma10: bool = False,
                 turn_up_mode: str = "relaxed",  # strict / relaxed / trend
                 min_turn_up_weeks: int = 1,
                 max_turn_up_weeks: int = 4):
        super().__init__(topk=topk)
        self.require_vol_confirm = require_vol_confirm
        self.require_price_above_ma10 = require_price_above_ma10
        self.turn_up_mode = turn_up_mode
        self.min_turn_up_weeks = min_turn_up_weeks
        self.max_turn_up_weeks = max_turn_up_weeks

    def run(self, universe: list[str], progress_cb=None) -> StrategyResult:
        """核心运行方法"""
        self._report(progress_cb, 10, f"分析 {len(universe)} 支股票...")
        
        # 初始化 Qlib
        from core.qlibhelper import qlib_safeinit
        qlib_safeinit()
        
        from qlib.data import D
        import datetime
        
        end_date = datetime.datetime.now().strftime("%Y-%m-%d")
        start_date = (datetime.datetime.now() - datetime.timedelta(days=120)).strftime("%Y-%m-%d")

        scores = {}
        total = len(universe)
        
        for i, ticker in enumerate(universe):
            try:
                # 从 Qlib 获取数据（推荐方式）
                df = D.features([ticker], ['$close', '$volume'], 
                              start_time=start_date, end_time=end_date, freq='day')
                
                if df.empty:
                    continue
                
                close_prices = df['$close'].dropna()
                
                if len(close_prices) < 15:  # 至少需要15天数据
                    continue
                
                # 计算 MA10
                ma10 = close_prices.rolling(10).mean()
                
                # 根据模式判断是否抬头
                is_turn_up = False
                turn_up_strength = 0
                
                if self.turn_up_mode == "strict":
                    is_turn_up, turn_up_strength = self._check_strict_turn_up(ma10)
                elif self.turn_up_mode == "relaxed":
                    is_turn_up, turn_up_strength = self._check_relaxed_turn_up(ma10)
                elif self.turn_up_mode == "trend":
                    is_turn_up, turn_up_strength = self._check_trend_turn_up(ma10)
                
                if not is_turn_up:
                    continue
                
                # 可选过滤：成交量确认
                if self.require_vol_confirm:
                    volume = df['$volume'].dropna() if '$volume' in df.columns else None
                    if volume is not None and len(volume) >= 5:
                        vol_ma5 = volume.rolling(5).mean()
                        if volume.iloc[-1] <= vol_ma5.iloc[-1]:
                            continue
                
                # 可选过滤：股价在 MA10 之上
                if self.require_price_above_ma10:
                    if close_prices.iloc[-1] <= ma10.iloc[-1]:
                        continue
                
                # 计算综合分数
                score = self._calculate_score(turn_up_strength, ma10, close_prices)
                scores[ticker.upper()] = score
                
            except Exception as e:
                logger.debug(f"处理 {ticker} 失败: {e}")
                continue
            
            if (i + 1) % 10 == 0:
                self._report(progress_cb, 20 + int(60 * i / total), 
                             f"分析中 {i+1}/{total}...")

        self._report(progress_cb, 90, f"完成，{len(scores)} 支满足条件")

        # 排序取 Top-K
        if scores:
            scores_series = pd.Series(scores, name="score").sort_values(ascending=False)
            topk = min(self.topk, len(scores_series))
            topk_tickers = scores_series.head(topk).index.tolist()
        else:
            scores_series = pd.Series(dtype=float)
            topk_tickers = []

        self._report(progress_cb, 100, f"选出 {len(topk_tickers)} 支")

        return StrategyResult(
            strategy_key=self.KEY,
            strategy_name=self.NAME,
            scores=scores_series,
            topk_tickers=topk_tickers,
            model_name=f"MA10 Turn-Up ({self.turn_up_mode}模式)",
            universe_size=len(universe),
        )

    def _check_strict_turn_up(self, ma10: pd.Series) -> tuple[bool, float]:
        """严格模式：本周刚刚抬头（cur > prev 且 prev <= prev2）"""
        if len(ma10) < 3:
            return False, 0
        cur_ma = ma10.iloc[-1]
        prev_ma = ma10.iloc[-2]
        prev2_ma = ma10.iloc[-3]
        is_turn_up = (cur_ma > prev_ma) and (prev_ma <= prev2_ma)
        strength = (cur_ma - prev_ma) / prev_ma if prev_ma != 0 else 0
        return is_turn_up, strength

    def _check_relaxed_turn_up(self, ma10: pd.Series) -> tuple[bool, float]:
        """放宽模式：已抬头1-4周（连续上升若干周）"""
        if len(ma10) < 8:
            return False, 0
        
        lookback = min(self.max_turn_up_weeks + 2, len(ma10))
        recent_ma = ma10.iloc[-lookback:].values
        
        turn_up_weeks = 0
        total_strength = 0
        
        for i in range(1, len(recent_ma)):
            if recent_ma[i] > recent_ma[i-1]:
                turn_up_weeks += 1
                strength = (recent_ma[i] - recent_ma[i-1]) / recent_ma[i-1] if recent_ma[i-1] != 0 else 0
                total_strength += strength
            else:
                turn_up_weeks = 0
                total_strength = 0
        
        is_turn_up = (self.min_turn_up_weeks <= turn_up_weeks <= self.max_turn_up_weeks)
        avg_strength = total_strength / turn_up_weeks if turn_up_weeks > 0 else 0
        return is_turn_up, avg_strength

    def _check_trend_turn_up(self, ma10: pd.Series) -> tuple[bool, float]:
        """趋势模式：MA10整体向上趋势（线性回归判断）"""
        if len(ma10) < 8:
            return False, 0
        
        x = np.arange(len(ma10))
        slope, _ = np.polyfit(x, ma10.values, 1)
        
        is_trend_up = slope > 0
        
        # 计算最近的加速度
        if len(ma10) >= 4:
            recent_slope1 = (ma10.iloc[-1] - ma10.iloc[-2]) / ma10.iloc[-2] if ma10.iloc[-2] != 0 else 0
            recent_slope2 = (ma10.iloc[-2] - ma10.iloc[-3]) / ma10.iloc[-3] if ma10.iloc[-3] != 0 else 0
            acceleration = recent_slope1 - recent_slope2
        else:
            acceleration = 0
        
        return is_trend_up, slope + acceleration

    def _calculate_score(self, turn_up_strength: float, ma10: pd.Series, close_prices: pd.Series) -> float:
        """计算综合分数"""
        # 1. 抬头强度（权重最高）
        strength_score = turn_up_strength * 1000
        
        # 2. 股价相对 MA10 位置
        price_position = (close_prices.iloc[-1] - ma10.iloc[-1]) / ma10.iloc[-1] if ma10.iloc[-1] != 0 else 0
        position_score = price_position * 500
        
        # 3. 趋势稳定性（波动越小越稳定）
        if len(ma10) >= 5:
            recent_changes = ma10.pct_change().dropna().tail(4)
            stability = 1 - recent_changes.std()
            stability_score = stability * 200
        else:
            stability_score = 0
        
        return round(strength_score + position_score + stability_score, 4)

    def _report(self, cb, pct: int, msg: str) -> None:
        if cb:
            try:
                cb(pct, msg)
            except Exception:
                pass
        logger.debug(f"[{self.KEY}] {pct}% - {msg}")
```

**策略模式说明**：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| `strict` | 必须刚刚抬头（当天 > 昨天，昨天 <= 前天） | 捕捉拐点，灵敏度高 |
| `relaxed` | 已抬头1-4周（连续上升） | 确认趋势，假信号少 |
| `trend` | 整体向上趋势（线性回归） | 长线趋势跟踪 |

**打分机制详解**：

| 维度 | 计算公式 | 权重 | 说明 |
|------|---------|------|------|
| 抬头强度 | `slope * 1000` | 62.5% | MA10斜率，越陡分数越高 |
| 股价位置 | `(price - ma10)/ma10 * 500` | 31.25% | 股价在MA10之上越多越好 |
| 趋势稳定性 | `(1 - std) * 200` | 6.25% | 波动越小越稳定 |

## 4. 数据获取方式对比

策略可以选择不同的数据来源：

| 数据来源 | 方法 | 优点 | 缺点 |
|---------|------|------|------|
| **Qlib** | `D.features([ticker], fields, ...)` | 统一数据接口，已预处理 | 需要先初始化 Qlib |
| **yfinance** | `yf.download(tickers, period, ...)` | 无需初始化，实时数据 | 需要处理数据格式 |

**推荐选择**：
- 如果已有 Qlib 数据且需要与 ML 策略保持一致 → 使用 Qlib
- 如果需要最新数据或快速验证 → 使用 yfinance

## 5. 策略打分与排序机制

所有策略都通过分数排序，分越高越好。针对传统策略的分数设计：

| 策略类型 | 分数来源 | 示例 |
|---------|---------|------|
| MA10 抬头 | 抬头强度 + 股价位置 + 稳定性 | 加权求和 |
| 双均线金叉 | 金叉强度（快线-慢线）/ 慢线 | `(ma5 - ma20) / ma20 * 100` |
| MACD 底背离 | DIF 与价格背离程度 | 标准化背离幅度 |
| RSI 超卖反弹 | 超卖程度 | `(30 - RSI)`，RSI 越低分数越高 |
| 多因子综合 | 各因子加权求和 | `w1*动量 + w2*波动率 + w3*成交量` |

**原则**：
- 分数必须正相关（越高 = 越好）
- 跨股票可比（同一套算法）
- 避免 NaN/Inf（使用过滤或 `np.nan_to_num`）
