## 📊 六维技术评分系统深度分析

### **一、系统概述**

**文件位置**：`stock_analysis/technical_scorer.py`

**设计理念**：
- 基于原始 OHLCV 数据计算**人类可读**的技术信号
- 与 Alpha158（机器学习特征）**互补**，提供可解释性强的技术分析
- 参考 daily_stock_analysis 的加权评分体系

---

### **二、六大维度详解**

#### **📈 维度1：MA 趋势（30%权重）**

**函数**：`_score_ma_trend()` (第186-226行)

**评分逻辑**：
```python
基础分 = 50分

# 1. 价格相对均线位置（±20分）
above_ratio = 价格在均线上方的比例
score += (above_ratio - 0.5) × 40

# 2. 均线排列（±15分）
bull_ratio = 短均线>长均线的配对比例
score += (bull_ratio - 0.5) × 30

# 3. 价格 > MA5 强化（±8分）
if price > MA5 × 1.01: score += 8   # 强势
if price < MA5 × 0.99: score -= 8   # 弱势
```

**打分标准**：
```
多头排列（MA5>MA10>MA20>MA60 且 价格>MA5）→ 85-100分 ✅
部分多头 → 60-80分
横盘震荡 → 40-60分
空头排列 → 0-40分 ❌
```

**评价**：✅ 考虑了均线数量和排列完整性，比简单判断更全面。

---

#### **📉 维度2：背离率（20%权重）**

**函数**：`_score_deviation()` (第228-262行)

**核心指标**：价格相对 MA20 的偏离百分比

**评分标准**：
```python
dev_pct = (price / MA20 - 1) × 100

偏离度              分数    含义
─────────────────────────────────────
> +10%             20分    严重高估/追涨 ⚠️⚠️
+5% ~ +10%         35分    追涨警戒 ⚠️
+3% ~ +5%          50分    轻微偏高
-3% ~ +3%          65分    健康区间 ✅
-5% ~ -3%          75分    轻微回调，买入机会
-10% ~ -5%         80分    超跌，价值区 ✅✅
< -10%             55分    大幅超跌，趋势破坏
```

**特殊标记**：
```python
chase_warning = dev_pct > 5.0  # 追涨警告标志
```

**评价**：✅ 巧妙地将"靠近均线"视为最佳状态，避免追高风险。

---

#### **📊 维度3：量能模式（15%权重）**

**函数**：`_score_volume()` (第264-319行)

**核心逻辑**：量价配合度分析

**评分标准**：
```python
vol_ratio = 当日成交量 / 5日均量

场景                    分数    含义
───────────────────────────────────────────
上涨 + 放量(>1.2)       80分    最佳 ✅✅
上涨 + 平量             65分    正常
上涨 + 缩量(<0.8)       55分    需验证 ⚠️
横盘                    50分    中性
下跌 + 平量             45分    一般
下跌 + 缩量(<0.8)       70分    洗盘 ✅
下跌 + 放量(>1.5)       25分    出货 ⚠️⚠️
```

**额外加分**：
```python
# 近5日 vs 近10日量能趋势
if vol_5d_avg / vol_10d_avg > 1.2: score += 5   # 量能放大
if vol_5d_avg / vol_10d_avg < 0.8: score -= 5   # 量能萎缩
```

**评价**：✅ 经典的量价关系理论实现，符合道氏理论。

---

#### **📉 维度4：MACD（15%权重）**

**函数**：`_score_macd()` (第321-394行)

**参数**：标准 MACD (12, 26, 9)

**评分逻辑**：
```python
基础分 = 50分

# 1. MACD线方向（±15分）
if MACD > 0: score += 15   # 零轴上方
else:        score -= 15   # 零轴下方

# 2. MACD vs Signal（±10分）
if MACD > Signal: score += 10   # 多头
else:             score -= 10   # 空头

# 3. 柱状图方向和变化（±15分）
if hist > 0:
    score += 8
    if hist > hist_prev: score += 7  # 动能增强
else:
    score -= 8
    if hist < hist_prev: score -= 7  # 动能减弱

# 4. 金叉/死叉（±10分）
if 金叉: score += 10
  if MACD > 0: score += 5  # 零轴上方金叉最强
if 死叉: score -= 10
```

**金叉/死叉判断**：
```python
# 近3根柱子内穿越零轴
if hist[-2] < 0 and hist[-1] > 0: cross = "金叉"
if hist[-2] > 0 and hist[-1] < 0: cross = "死叉"
```

**评价**：✅ 综合考虑了MACD的三个要素（位置、交叉、动能），逻辑严密。

---

#### **📈 维度5：RSI 动量（10%权重）**

**函数**：`_score_rsi()` (第396-451行)

**参数**：三周期 RSI (6, 12, 24)

**评分逻辑**：
```python
avg_rsi = (RSI6 + RSI12 + RSI24) / 3

平均RSI              分数    含义
─────────────────────────────────────
< 20                90分    深度超卖 ✅✅
20 ~ 30             80分    超卖 ✅
30 ~ 40             65分    弱势偏低
40 ~ 50             55分    中性偏空
50 ~ 60             55分    中性偏多
60 ~ 70             60分    偏强
70 ~ 80             35分    超买警告 ⚠️
> 80                20分    深度超买 ⚠️⚠️
```

**动量修正**：
```python
if RSI6 > RSI12: score += 5   # 短期动量向上
else:            score -= 5   # 短期动量向下
```

**评价**：✅ 使用三周期平均更稳定，RSI6方向修正增加灵敏度。

#### **📊 维度6：布林带位置（10%权重）**

**函数**：`_score_bband()` (第453-497行)

**核心指标**：%B = (price - lower) / (upper - lower)

**评分标准**：
```python
%B值               分数    含义
─────────────────────────────────────
< 0.1              85分    触下轨，超跌反弹 ✅✅
0.1 ~ 0.25         72分    下轨附近 ✅
0.25 ~ 0.4         62分    偏低
0.4 ~ 0.6          55分    中间区域
0.6 ~ 0.75         48分    偏高
0.75 ~ 0.9         35分    上轨附近 ⚠️
> 0.9              20分    触上轨，超买 ⚠️⚠️
```

**评价**：✅ 均值回归策略的经典实现，低%B值高分符合抄底逻辑。

### **三、综合评分计算**

**加权公式**（第144-163行）：
```python
total_score = Σ(维度分数 × 权重) / Σ(可用维度权重)

权重分配：
• MA 趋势：    30%
• 背离率：     20%
• 量能模式：   15%
• MACD：       15%
• RSI 动量：   10%
• 布林带：     10%
━━━━━━━━━━━━━━━━━━━━━━━
总计：        100%
```

**动态调整**：如果某些维度数据不足（如缺少volume），自动重新分配权重。

### **六、优势与特色**

#### **✅ 优点**

1. **可解释性强**
   - 每个维度都有明确的业务含义
   - 不同于Alpha158的黑盒特征

2. **多维度平衡**
   - 趋势（MA）、动量（RSI/MACD）、位置（布林带）、量能全覆盖
   - 权重分配合理

3. **风险控制**
   - `chase_warning` 追涨警告机制
   - 背离率过高会大幅扣分

4. **容错性好**
   - 数据不足时自动跳过该维度
   - 动态权重归一化

5. **经典理论支撑**
   - 量价关系、均线理论、布林带、MACD、RSI
   - 都是经过市场验证的技术指标

#### **⚠️ 潜在改进点**

1. **波动率未纳入**
   - 建议增加 ATR（平均真实波幅）作为风险控制维度

2. **时间周期固定**
   - 所有指标都用日线，可增加周线/小时线多周期共振

3. **行业对比缺失**
   - 可与同行业股票对比相对强弱

4. **阈值可调性**
   - 当前阈值硬编码，建议配置文件化

### **七、实际应用示例**

假设某股票当前数据：
```
价格：$150
MA5: $148, MA10: $145, MA20: $142, MA60: $138
成交量：1.5倍于5日均量
MACD: 金叉，零轴上方
RSI6/12/24: 55/52/50
布林带 %B: 0.3
```

**评分计算**：
```
MA 趋势：    85分（多头排列）× 30% = 25.5
背离率：     72分（偏离+5.6%，轻微追涨）× 20% = 14.4
量能模式：   80分（上涨放量）× 15% = 12.0
MACD：       90分（零轴上金叉）× 15% = 13.5
RSI：        55分（中性）× 10% = 5.5
布林带：     62分（偏低）× 10% = 6.2
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
总分：       77.1分 → "强买" ✅✅
```

### **八、总结**

**六维技术评分系统是项目的亮点之一**：

1. ✅ **填补空白**：在AI模型之外提供传统技术分析的视角
2. ✅ **用户友好**：散户能理解的技术指标，而非黑盒分数
3. ✅ **风控意识**：追涨警告、超买超卖提示
4. ✅ **工程优秀**：代码规范、异常处理完善、日志清晰

**与 yfinance fallback 的区别**：
- **六维评分**：用于个股深度分析，7个维度精细打分
- **yfinance fallback**：用于选股兜底，简化版多维打分

两者设计理念相似，但应用场景不同，形成互补！
