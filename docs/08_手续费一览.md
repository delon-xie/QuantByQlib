## 核心差异总结

### 1. 印花税/交易税政策
- **卖出单边收税**：A股(0.05%)、台湾(0.3%)、韩国(0.2%) → 导致 `close_cost` 显著高于 `open_cost`
- **双边收税**：港股(0.1%×2) → 买卖费率对称
- **无印花税**：美股、日本、虚拟币 → 买卖费率对称

### 2. 最低佣金 (min_cost) 影响
- **毁灭性高门槛**：韩国(20000 KRW ≈ 15 USD)、A股(5 CNY ≈ 0.7 USD) → 对小额交易策略几乎致命
- **中等门槛**：港股(100 HKD ≈ 13 USD)、日本(100 JPY ≈ 0.7 USD)
- **低门槛**：美股(1 USD)、台湾(1 TWD ≈ 0.2 CNY) → 对小额交易友好
- **无门槛**：虚拟币(0)

### 3. 回测建议
- **A股**：必须区分买卖费率 (`close_cost > open_cost`)
- **港股**：传统配置取高值(100)，若模拟互联网券商可降至 5-10
- **日韩**：注意货币单位换算
- **台湾**：核心是卖出税，最低成本可忽略

## 完整配置函数

```python
def get_exchange_config(reg: str, conservative: bool = True) -> dict:
    """
    获取全球交易所回测成本配置
    
    Args:
        reg: 地区代码 (cn|hk|us|bt|jp|kr|tw)
        conservative: True=保守配置(高摩擦), False=激进配置(低摩擦)
    
    Returns:
        dict: 包含 open_cost, close_cost, min_cost 的配置字典
    """
    
    # 保守配置 (高摩擦，适合风控严格的回测)
    conservative_config = {
        "cn": {"open_cost": 0.0005, "close_cost": 0.00105, "min_cost": 5.0},
        "hk": {"open_cost": 0.00236, "close_cost": 0.00236, "min_cost": 100.0},
        "us": {"open_cost": 0.0001, "close_cost": 0.0001, "min_cost": 1.0},
        "bt": {"open_cost": 0.001, "close_cost": 0.001, "min_cost": 0.0},
        "jp": {"open_cost": 0.0015, "close_cost": 0.0015, "min_cost": 100.0},
        "kr": {"open_cost": 0.0035, "close_cost": 0.0055, "min_cost": 20000.0},
        "tw": {"open_cost": 0.0005, "close_cost": 0.0035, "min_cost": 1.0},
    }
    
    # 激进配置 (低摩擦，适合互联网券商/低成本通道)
    aggressive_config = {
        "cn": {"open_cost": 0.00025, "close_cost": 0.0008, "min_cost": 5.0},  # 印花税不能少
        "hk": {"open_cost": 0.0015, "close_cost": 0.0015, "min_cost": 10.0},  # 互联网券商
        "us": {"open_cost": 0.00005, "close_cost": 0.00005, "min_cost": 0.0},  # 零佣金
        "bt": {"open_cost": 0.0007, "close_cost": 0.0007, "min_cost": 0.0},  # VIP费率
        "jp": {"open_cost": 0.0008, "close_cost": 0.0008, "min_cost": 0.0},  # 零佣金券商
        "kr": {"open_cost": 0.0025, "close_cost": 0.0045, "min_cost": 5000.0},  # 互联网券商
        "tw": {"open_cost": 0.0003, "close_cost": 0.0033, "min_cost": 0.0},  # 零低消
    }
    
    config = conservative_config if conservative else aggressive_config
    return config.get(reg, config["cn"])  # 默认返回A股配置


def get_exchange_kwargs(reg: str, conservative: bool = True) -> dict:
    """
    获取完整的 Qlib exchange_kwargs 配置
    
    Args:
        reg: 地区代码
        conservative: 是否使用保守配置
    
    Returns:
        dict: 完整的 exchange_kwargs
    """
    cost_config = get_exchange_config(reg, conservative)
    
    # 基础配置
    exchange_kwargs = {
        "freq": "day",
        "limit_threshold": 0.095,  # 涨跌停限制
        "deal_price": "close",  # 成交价
        "open_cost": cost_config["open_cost"],
        "close_cost": cost_config["close_cost"],
        "min_cost": cost_config["min_cost"],
    }
    
    # 地区特定配置
    if reg == "bt":  # 虚拟币
        exchange_kwargs.update({
            "limit_threshold": 0.5,  # 虚拟币波动大
            "volume_limit": False,  # 无涨跌停
        })
    
    return exchange_kwargs
```

## 重要提醒

1.  **货币单位一致性**：确保账户资金单位与 `min_cost` 单位匹配。如需统一为USD，需进行汇率换算。
2.  **税制变更**：印花税/证交税可能调整，需关注当地最新政策。
3.  **券商差异**：同一市场不同券商的费率差异巨大，建议根据模拟的券商类型选择保守/激进配置。
4.  **ETF特殊规则**：ETF的税率通常低于股票（如台湾ETF卖出税0.1%），需单独处理。
