```python
# optimization/strategy_executor.py
def create_strategy(cls, strategy_key: str, **params) -> BaseStrategy:
    # 动态导入策略类
    module_path, class_name = cls._STRATEGY_MAP[strategy_key]
    module = importlib.import_module(module_path)
    strategy_class = getattr(module, class_name)
    
    # 使用传入的参数创建策略实例
    return strategy_class(**params)  # ← 关键点：**params 覆盖默认值
```

## 二、硬编码权重的问题

### 问题定位

**策略内部的硬编码权重**（以 `trendline_breakout` 为例）：

```python
# strategies/screening/trendline_breakout_screening.py
def _calculate_breakout_score(self, break_ratio, trend_slope, close_prices, volume):
    score = 0
    # ⚠️ 硬编码权重！
    score += min(break_ratio * 100, 50)           # 突破幅度权重50%
    score += min(trend_strength * 10000, 20)       # 趋势强度权重20%
    score += min(recent_volatility < 2, 10) * 10   # 蓄势权重10%
    score += min(today_change > 0.02, 10) * 10     # K线形态权重10%
    score += min(vol_ratio > 1.5, 10) * 10         # 成交量权重10%
    return score
```

## 三、优化器工作原理

### 网格搜索流程

```python
# optimization/optimizer.py
class GridSearchOptimizer:
    def optimize(self, executor, param_specs):
        # 1. 生成参数网格
        param_grid = self._generate_grid(param_specs)  # 如: 500+组参数
        
        # 2. 遍历所有组合
        for params in param_grid:
            # 3. 创建策略实例（参数注入）
            strategy = executor.create_strategy(strategy_key, **params)
            
            # 4. 运行策略回测
            result = strategy.run(universe, prices)
            
            # 5. 计算多目标评分
            score = self._calculate_score(result)
            
            # 6. 记录最优解
            if score > best_score:
                best_params = params
        
        return best_params
```

### 参数注入机制

```
优化器生成参数组合 → **params 解包 → 策略 __init__ 接收
```

**示例**：
```python
# 优化器生成
params = {
    "breakthrough_threshold": 0.04,
    "volume_confirmation_ratio": 1.8,
    "trendline_points": 25

# 策略初始化

# 等价于
strategy = TrendlineBreakoutStrategy(
    breakthrough_threshold=0.04,

    trendline_points=25,
    # 未指定的参数使用默认值
    min_trend_duration=10,
    consolidation_days=3,
    retest_confirmation=True
)
```

## 四、如何优化硬编码权重

### 方案1：将权重参数化（推荐）

**步骤1：修改策略 `__init__`**

class TrendlineBreakoutStrategy(BaseStrategy):
    def __init__(
        self,
        # 原有参数...
        weight_break_ratio: float = 0.5,    # 突破幅度权重
        weight_trend_strength: float = 0.2, # 趋势强度权重
        weight_accumulation: float = 0.1,   # 蓄势权重
        weight_candle: float = 0.1,         # K线形态权重
        weight_volume: float = 0.1          # 成交量权重
    ):
        self.weights = {
            "break_ratio": weight_break_ratio,
            "trend_strength": weight_trend_strength,
            "accumulation": weight_accumulation,
            "candle": weight_candle,
            "volume": weight_volume
        }
    
    def _calculate_breakout_score(self, ...):
        score = (
            self.weights["break_ratio"] * min(break_ratio * 200, 100) +
            self.weights["trend_strength"] * min(trend_strength * 50000, 100) +
            # ...
        )
        return score

# 添加权重归一化约束
class TrendlineBreakoutStrategy(BaseStrategy):
    def __init__(self, weights: list[float] = None):
        if weights is None:
            self.weights = [0.5, 0.2, 0.1, 0.1, 0.1]
        else:
            # 归一化处理
            total = sum(weights)
            self.weights = [w / total for w in weights]

## 八、总结

### 当前优化器的能力

- **只能优化在 `param_specs` 中明确定义的参数**
- 未定义的参数使用策略默认值
- 硬编码权重不在优化范围内

### 优化硬编码权重的步骤

1. **识别硬编码权重**：检查策略内部的评分公式
2. **参数化改造**：将权重添加到策略 `__init__`
3. **更新配置**：在 `param_specs` 中定义权重参数范围
4. **重新运行优化**：优化器会自动遍历权重组合

---

**结论**：要优化策略内部的硬编码权重，需要先将这些权重参数化，添加到策略的 `__init__` 参数中，并在 `STRATEGY_PARAMS_MAP` 中配置对应的参数规格。
