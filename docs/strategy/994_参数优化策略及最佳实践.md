# 参数优化策略及最佳实践

## 一、参数优化策略对比

### 策略1：全参数同时优化

**优点**：
- 可以发现参数间的交互效应
- 全局最优解搜索
- 代码实现简单

**缺点**：
- 组合爆炸（维度诅咒）
- 计算成本极高
- 容易过拟合

**适用场景**：参数数量少（≤4个）、计算资源充足

---

### 策略2：逐一参数优化（贪心策略）

**步骤**：
```
1. 固定其他参数为默认值，优化参数A → 得到A的最优值
2. 固定A为最优值，优化参数B → 得到B的最优值
3. 重复直到所有参数优化完毕
```

**优点**：
- 计算量小（线性增长）
- 易于理解和实现

**缺点**：
- 可能陷入局部最优
- 忽略参数交互效应

**适用场景**：参数数量多、计算资源有限

---

### 策略3：分层优化（推荐）

**步骤**：
```
1. 识别参数优先级（通过敏感性分析）
2. 高优先级参数：精细搜索
3. 低优先级参数：粗略搜索或固定
4. 逐步精化
```

**代码示例**：
```python
# 分层参数配置
HIGH_PRIORITY_PARAMS = [
    StrategyParamSpec("breakthrough_threshold", "float", 0.03, [0.01, 0.06], step=0.005),
    StrategyParamSpec("volume_confirmation_ratio", "float", 1.5, [1.2, 2.5], step=0.1),
]

LOW_PRIORITY_PARAMS = [
    StrategyParamSpec("trendline_points", "int", 20, [15, 25], step=5),  # 稀疏采样
    StrategyParamSpec("retest_confirmation", "choice", True, [True, False]),
]
```

---

### 策略4：贝叶斯优化（自适应）

**原理**：
```
1. 用高斯过程建模目标函数
2. 根据已评估点自适应选择下一个评估点
3. 平衡探索（未知区域）和利用（已知好区域）
```

**代码实现**：
```python
from skopt import gp_minimize

result = gp_minimize(
    objective,           # 目标函数
    dimensions,          # 参数空间
    n_calls=50,          # 总评估次数（远少于网格搜索）
    n_initial_points=10, # 初始随机探索
)
```

## 四、参数敏感性分析

### 分析方法

```python
def analyze_sensitivity(best_params):
    """分析每个参数对策略表现的影响"""
    sensitivity = {}
    base_score = evaluate(best_params)
    
    for param_name, base_value in best_params.items():
        # 向上扰动 10%
        params_up = best_params.copy()
        params_up[param_name] = base_value * 1.1
        score_up = evaluate(params_up)
        
        # 向下扰动 10%
        params_down = best_params.copy()
        params_down[param_name] = base_value * 0.9
        score_down = evaluate(params_down)
        
        # 计算敏感度
        sensitivity[param_name] = abs(score_up - score_down) / (0.2 * base_score)
    
    return sensitivity
```

### 敏感度评估标准

| 敏感度范围 | 评估 | 处理策略 |
|------------|------|----------|
| > 0.15 | 🔴 高敏感 | 精细优化，小步长 |
| 0.05 - 0.15 | 🟡 中敏感 | 中等优化 |
| < 0.05 | 🟢 低敏感 | 可固定或粗略搜索 |

## 八、验证与迭代

### Walk-Forward 验证

```python
def walk_forward_validation(best_params, n_windows=5):
    """滚动窗口验证参数稳定性"""
    windows = split_into_windows(n_windows)
    
    train_scores = []
    test_scores = []
    
    for train_period, test_period in windows:
        # 在训练期重新优化
        train_score = optimize_on_period(best_params, train_period)
        train_scores.append(train_score)
        
        # 在测试期验证
        test_score = evaluate_on_period(best_params, test_period)
        test_scores.append(test_score)
    
    return {
        "avg_train_score": np.mean(train_scores),
        "avg_test_score": np.mean(test_scores),
        "test_score_std": np.std(test_scores),
        "param_stability": test_score_std < 0.15
    }
```

## 九、总结

### 核心原则

1. **不要盲目全参数优化**：先做敏感性分析
2. **分层优化**：高优先级参数精细搜索，低优先级参数粗略搜索
3. **利用贝叶斯优化**：参数数量较多时使用
4. **验证稳定性**：通过 Walk-Forward 验证参数鲁棒性

### 推荐流程

| 步骤 | 任务 | 输出 |
|------|------|------|
| 1 | 参数敏感性分析 | 参数优先级排序 |
| 2 | 分层优化配置 | P0/P1/P2参数分组 |
| 3 | 执行优化 | 最优参数组合 |
| 4 | Walk-Forward验证 | 参数稳定性报告 |
| 5 | 迭代精化 | 最终参数配置 |

---

**结论**：**最佳策略是分层优化**，先通过敏感性分析识别关键参数，对高优先级参数进行精细搜索，低优先级参数可以固定或粗略搜索，最后通过 Walk-Forward 验证稳定性。
