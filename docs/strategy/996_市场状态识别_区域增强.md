## 二、当前设计的问题

### 问题1：模型参数未按区域优化

**现状**：所有区域使用相同的HMM模型参数

```python
# 固定参数
N_STATES = 4  # 4个状态
N_ITER = 200  # 迭代次数
covariance_type = "diag"  # 协方差类型
```

**问题**：不同市场的波动性、周期特征差异很大：
- A股：政策驱动，波动较大
- US：机构主导，相对稳定
- HK：受内外因素影响，波动介于两者之间

---

### 问题2：状态定义的普适性问题

**统一状态定义**：
```python
_REGIME_LABELS_EN = ["recovery", "expansion", "overheating", "recession"]
_REGIME_LABELS_CN = {
    "recovery":    "复苏期",
    "expansion":   "扩张期",
    "overheating": "过热期",
    "recession":   "衰退期",
}
```

**潜在问题**：
- A股的"过热期"可能与美股定义不同
- 港股的"复苏期"特征可能独特
- 不同市场的周期长度差异很大

---

### 问题3：缺少区域特定特征

当前仅使用价格数据（收益率+波动率）：


## 三、最佳实践建议

### 方案1：区域特定模型训练

```python
class RegionalHMM:
    def __init__(self, reg: str):
        self.reg = reg
        self.model = self._load_regional_model()
    
    def _load_regional_model(self):
        """加载区域特定的预训练模型"""
        model_params = {
            "cn": {
                "covariance_type": "full",
                "n_components": 4,
                "n_iter": 300,
            },
            "us": {
                "covariance_type": "diag",
                "n_components": 4,
                "n_iter": 200,
            },
            "hk": {
                "covariance_type": "full",
                "n_components": 5,  # 港股可能需要更多状态
                "n_iter": 250,
            },
        }
        return GaussianHMM(**model_params[self.reg])
```

### 方案2：区域特征增强

```python
def _enrich_with_regional_features(df: pd.DataFrame, reg: str) -> pd.DataFrame:
    """添加区域特定特征"""
    df["return"] = df["Close"].pct_change()
    df["volatility"] = df["return"].rolling(20).std()
    
    if reg == "cn":
        # 添加A股特有特征
        df["shibor"] = _fetch_shibor_data(df.index)           # 银行间利率
        df["margin_balance"] = _fetch_margin_data(df.index)   # 融资余额
        df["northbound_flow"] = _fetch_northbound(df.index)   # 北向资金
    
    elif reg == "us":
        # 添加美股特有特征
        df["vix"] = _fetch_vix_data(df.index)                 # VIX指数
        df["treasury_yield"] = _fetch_treasury_data(df.index) # 国债收益率
        df["fed_rate"] = _fetch_fed_rate(df.index)            # 美联储利率
    
    elif reg == "hk":
        # 添加港股特有特征
        df["ah_premium"] = _fetch_ah_premium(df.index)        # AH溢价
        df["hkd_usd"] = _fetch_exchange_rate(df.index)        # 汇率
        df["southbound_flow"] = _fetch_southbound(df.index)   # 南下资金
    
    return df.dropna()
```

### 方案4：混合模型策略

```python
def run_regime_detection(reg: str, trade_date: date) -> dict:
    """区域自适应的市场状态识别"""
    
    if reg == "cn":
        # A股：结合政策事件的混合模型
        return _cn_regime_detection(trade_date)
    
    elif reg == "us":
        # US：传统HMM + VIX辅助
        return _us_regime_detection(trade_date)
    
    elif reg == "hk":
        # HK：考虑内外因素的双层模型
        return _hk_regime_detection(trade_date)
    
    else:
        # 默认：通用HMM
        return _generic_regime_detection(trade_date)


def _cn_regime_detection(trade_date: date) -> dict:
    """A股市场状态识别：政策驱动型"""
    # 1. HMM基础识别
    hmm_result = _run_hmm_detection(trade_date, reg="cn")
    
    # 2. 政策事件修正
    policy_events = _fetch_policy_events(trade_date)
    if policy_events["major_policy"]:
        hmm_result["regime"] = _adjust_by_policy(hmm_result, policy_events)
    
    return hmm_result


def _us_regime_detection(trade_date: date) -> dict:
    """美股市场状态识别：VIX辅助"""
    # 1. HMM基础识别
    hmm_result = _run_hmm_detection(trade_date, reg="us")
    
    # 2. VIX修正
    vix_level = _fetch_vix_level(trade_date)
    if vix_level > 30:
        hmm_result["regime"] = "recession"  # 高VIX强制衰退
    
    return hmm_result
```

## 五、总结

### 当前状态 vs 最佳实践

| 维度 | 当前状态 | 最佳实践 |
|------|----------|----------|
| **数据来源** | ✓ 已按区域适配 | 继续完善区域数据源 |
| **模型参数** | ✗ 统一参数 | 区域特定模型训练 |
| **状态定义** | ✗ 统一标签 | 区域语义映射 |
| **特征工程** | ✗ 通用特征 | 区域特征增强 |

---

### 关键改进点

1. **模型参数区域化**：不同市场使用不同的HMM参数
2. **特征增强**：添加各市场特有的经济指标
3. **状态语义适配**：状态标签与区域市场特征匹配
4. **事件驱动修正**：重大事件对市场状态的影响

---

**结论**：当前 `cn` 和 `us` 的市场状态识别使用**相同的HMM模型结构**，仅数据源不同。这可能导致识别准确性在不同市场上表现不一致。建议按区域训练独立的HMM模型，并添加区域特有特征，以提高跨市场的识别准确性。
