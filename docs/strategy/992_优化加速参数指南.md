# 策略优化加速参数指南

## 一、可调整的加速参数总览

| 参数类别 | 参数名称 | 默认值 | 加速方向 | 时间影响 |
|----------|----------|--------|----------|----------|
| **数据范围** | `start_date` | 2023-01-01 | 缩短时间范围 | 中 |
| **股票池** | `scope` | top20 | 减小股票池 | 高 |
| **网格搜索** | `grid_search_enabled` | True | 关闭或减少步长 | 高 |
| **贝叶斯优化** | `bayesian_enabled` | False | 启用 | 高 |
| **贝叶斯迭代** | `bayesian_n_iter` | 50 | 减少迭代次数 | 中 |
| **Walk-Forward** | `walkforward_enabled` | True | 关闭 | 中 |
| **WF窗口** | `wf_train_window` | 252 | 减小窗口 | 中 |
| **稳健性检验** | `robustness_enabled` | True | 关闭 | 中 |
| **蒙特卡洛** | `monte_carlo_n_sim` | 500 | 减少模拟次数 | 低 |

---

## 二、核心加速策略详解

### 1. 减少股票池大小（最有效）

**影响**：直接减少每轮回测的股票数量

**配置方式**：

```python
# optimization/config.py
class OptimizationConfig:
    scope: str = "top20"  # 修改为更小的范围
    
# 或在优化脚本中修改股票池获取逻辑
def _get_universe(self) -> list[str]:
    # 默认约100支，改为20支
    return StockScreener()._sp500_fallback()[:20]
```

**时间对比**：

| 股票数量 | 预估时间 | 说明 |
|----------|----------|------|
| 939支（全部） | 60-120分钟 | 完整优化 |
| 100支 | 30-60分钟 | 默认配置 |
| 20支 | 5-10分钟 | 快速测试 |

---

### 2. 使用贝叶斯优化

**影响**：从指数级搜索降为线性搜索

**配置方式**：

```bash
# 命令行
python examples/optimize_strategy.py --strategy early_trend --bayesian
```

```python
# 配置文件
class OptimizationConfig:
    bayesian_enabled: bool = True  # 启用贝叶斯优化
    bayesian_n_iter: int = 50      # 总评估次数
    bayesian_init_points: int = 10 # 初始随机点
```

**时间对比**：

| 优化方式 | 参数组合/评估次数 | 预估时间 |
|----------|-------------------|----------|
| 网格搜索 | 880组 | 30-60分钟 |
| 贝叶斯优化 | 50次 | 5-10分钟 |

---

### 3. 减少参数搜索空间

**影响**：减少参数组合数

**配置方式**：

```python
# optimization/config.py
EARLY_TREND_PARAMS = [
    # 原配置：较宽范围
    StrategyParamSpec("max_convergence_days", "int", 20, [10, 30], 2),
    StrategyParamSpec("max_slope", "float", 0.02, [0.01, 0.05], 1),
    
    # 加速配置：较窄范围
    StrategyParamSpec("max_convergence_days", "int", 20, [15, 25], 5),  # 3个值
    StrategyParamSpec("max_slope", "float", 0.02, [0.015, 0.035], 0.01),  # 3个值
]
```

**组合数计算**：

| 参数配置 | 组合数 | 时间 |
|----------|--------|------|
| 默认（11×5×4×4） | 880 | 30-60分钟 |
| 窄范围（3×3×3×3） | 81 | 3-6分钟 |

---

### 4. 关闭Walk-Forward验证

**影响**：跳过滚动窗口验证

**配置方式**：

```bash
# 命令行
python examples/optimize_strategy.py --strategy early_trend --no-wf
```

```python
# 配置文件
class OptimizationConfig:
    walkforward_enabled: bool = False  # 关闭Walk-Forward
```

**时间对比**：

| 配置 | Walk-Forward耗时 | 总时间 |
|------|------------------|--------|
| 开启 | 15-30分钟 | 60-120分钟 |
| 关闭 | 0 | 45-90分钟 |

---

### 5. 关闭稳健性检验

**时间对比**：

| 配置 | 稳健性检验耗时 | 总时间 |
|------|----------------|--------|
| 开启 | 10-20分钟 | 60-120分钟 |
| 关闭 | 0 | 50-100分钟 |

### 6. 缩短数据时间范围


```python
# 配置文件

```

**时间对比**：

| 时间范围 | 天数 | 时间 |
|----------|------|------|
| 2023-01-01 → 现在 | ~825天 | 60-120分钟 |
| 2025-01-01 → 现在 | ~375天 | 30-60分钟 |

## 八、总结

### 加速效果对比

| 配置 | 完整优化时间 | 加速后时间 | 加速比 |
|------|--------------|------------|--------|
| 完整配置 | 60-120分钟 | 60-120分钟 | 1x |
| 仅贝叶斯 | 60-120分钟 | 15-30分钟 | 4x |
| 贝叶斯+无WF | 60-120分钟 | 10-20分钟 | 6x |
| 全部加速 | 60-120分钟 | 5-10分钟 | 12x |

### 核心建议

1. **开发阶段**：使用 `--bayesian --no-wf --no-robustness --start 2025-01-01`
2. **参数探索**：使用 `--bayesian`
3. **最终优化**：使用完整配置
4. **CI/CD**：使用 `--bayesian --no-wf --no-robustness`

---

**结论**：最有效的加速方式是启用贝叶斯优化（`--bayesian`），其次是关闭Walk-Forward验证（`--no-wf`）和减少股票池大小。
