# 策略优化框架 — 使用说明

## 一、快速开始

### 命令行（推荐）

```bash
# 优化单个策略（默认 Early Trend）
python examples/optimize_strategy.py --strategy early_trend

# 指定日期范围
python examples/optimize_strategy.py --strategy golden_cross --start 2022-01-01

# 使用贝叶斯优化（高维参数更高效）
python examples/optimize_strategy.py --strategy ma10 --bayesian

# 只跑参数搜索，跳过 Walk-Forward 和稳健性（快速验证）
python examples/optimize_strategy.py --strategy trendline_breakout --no-wf --no-robustness

# 批量优化全部 4 个策略
python examples/optimize_strategy.py --all
```

输出位置：`~/Documents/A股交易日记/reports/optimization/` 下生成 Markdown 报告 + PNG 图表。

### Python API

```python
from optimization import OptimizationConfig, OptimizationController, OptimizationReporter

# 使用预设参数规格
from optimization.config import STRATEGY_PARAMS_MAP

config = OptimizationConfig(
    strategy_key="early_trend",
    param_specs=STRATEGY_PARAMS_MAP["early_trend"],
    start_date="2023-01-01",
)

controller = OptimizationController(config)
result = controller.run()          # 运行完整流水线

reporter = OptimizationReporter()
report_path = reporter.generate(result)
print(f"报告: {report_path}")
```

## 三、自定义参数优化

### 缩小搜索范围（快速调试）

```python
from optimization.config import OptimizationConfig, StrategyParamSpec

# 只优化 2 个最关键参数，用很窄的范围
my_params = [
    StrategyParamSpec("max_convergence_days", "int", 20, [15, 25], 1),
    StrategyParamSpec("max_slope", "float", 0.02, [0.015, 0.030], 1),
]

config = OptimizationConfig(
    strategy_key="early_trend",
    param_specs=my_params,
    start_date="2024-06-01",
    walkforward_enabled=False,    # 关掉慢的部分
    robustness_enabled=False,
)
```

### 自定义目标权重

```python
from optimization.objective import ObjectiveFunction

# 保守型：更看重回撤控制
conservative = ObjectiveFunction(
    weights={
        "max_drawdown": 0.40,
        "sharpe_ratio": 0.30,
        "total_return": 0.15,
        "win_rate": 0.10,
        "profit_factor": 0.05,
    }
)

# 激进型：更看重收益
aggressive = ObjectiveFunction(
    weights={
        "total_return": 0.40,
        "sharpe_ratio": 0.25,
        "max_drawdown": 0.15,
        "win_rate": 0.10,
        "profit_factor": 0.10,
    }
)
```

### 使用贝叶斯优化

```python
config = OptimizationConfig(
    strategy_key="golden_cross",
    param_specs=STRATEGY_PARAMS_MAP["golden_cross"],
    bayesian_enabled=True,        # 启用贝叶斯
    bayesian_n_iter=50,           # 评估 50 次（远少于网格）
    bayesian_init_points=10,      # 前 10 次随机探索
```

## 六、数据源优先级

框架按以下顺序获取数据（自动降级）：

```
1. Qlib 本地数据 (D.features)   ← 最快，离线可用
2. yfinance 批量下载            ← 需要网络
3. MarketDataClient 逐个获取     ← OpenBB → yfinance 保底
```

Qlib 数据初始化后，优先使用本地数据，速度远快于网络下载。

## 七、模块单独使用

框架每个模块都可独立调用，不依赖完整流水线：

```python
# 只用 DataManager 获取数据
from optimization import DataManager
dm = DataManager()
prices = dm.fetch_prices_batch(["AAPL", "MSFT"], "2024-01-01", "2024-12-31")
regime = dm.get_market_regime()

# 只用 EnhancedBacktester 回测
from optimization import EnhancedBacktester
bt = EnhancedBacktester(stop_loss_config={"fixed": 0.05})
result = bt.run_signal_backtest(["AAPL", "MSFT"], prices)
print(result["metrics"].sharpe_ratio)

# 只用 ObjectiveFunction 打分
from optimization import ObjectiveFunction
from backtesting.performance_metrics import BacktestMetrics

obj = ObjectiveFunction(market_regime="recession")
metrics = BacktestMetrics(sharpe_ratio=1.5, max_drawdown=-0.15, total_return=0.3)
score = obj.calculate(metrics)
print(f"Score: {score:.4f}")

# 只用 RobustnessChecker 检验
from optimization import RobustnessChecker, OptimizationConfig
config = OptimizationConfig(strategy_key="early_trend", param_specs=...)
checker = RobustnessChecker(config)
mc = checker.monte_carlo(best_params, prices, universe)

# 只用 Optimizer 搜参
from optimization import GridSearchOptimizer
gs = GridSearchOptimizer(config)
result = gs.search(prices, universe)
```

## 八、常见问题

**Q: 运行报 "ModuleNotFoundError: No module named 'qlib'"**
→ Qlib 未安装，自动降级 yfinance。功能正常，只是不能用本地数据加速。

**Q: 网格搜索太慢？**
→ 减少参数数量或缩小搜索范围：
```python
# 从 4 参数 x 10 步 = 10000 组合 → 2 参数 x 4 步 = 16 组合
my_params = [
    StrategyParamSpec("max_slope", "float", 0.02, [0.01, 0.03], 1),
    StrategyParamSpec("max_convergence_days", "int", 20, [15, 25], 2),
]
```

**Q: 贝叶斯优化 vs 网格搜索？**
→ 参数 ≤ 3 个用网格（组合数可控），≥ 4 个用贝叶斯（更高效）。

**Q: 如何只优化特定参数组合？**
→ 自定义 `param_specs` 列表，只包含要优化的参数。未列出的参数使用策略默认值。
