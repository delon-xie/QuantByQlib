# 策略设计文档：MA10抬头策略 (MA10 Turn-Up Strategy)

## 1. 策略概述

**策略名称**: MA10抬头策略  
**策略标识符**: `ma10_turnup`  
**策略类型**: 技术指标选股  
**核心目标**: 捕捉10日均线的抬头信号，识别短期上涨趋势启动点

### 1.1 设计背景

MA10（10日移动平均线）是重要的短期趋势指标。MA10由下降转为上升（即"抬头"）往往预示着短期趋势由弱转强。本策略专注于识别这一关键转折点，同时提供多种模式以适应不同的市场环境。

### 1.2 核心思想

- **趋势转折识别**: MA10抬头是短期趋势转折的重要信号
- **多模式设计**: 支持严格模式（刚刚抬头）、放宽模式（已抬头1-4周）、趋势模式（整体向上）
- **时间衰减**: 信号强度随时间推移自然衰减
- **综合评分**: 结合抬头强度、股价位置、趋势稳定性多维度评分

## 3. 抬头模式详解

### 3.1 严格模式 (strict)

**原理**: 必须在当前周期刚刚发生MA10抬头。

**判断条件**:
```
当前MA10 > 前一日MA10  且  前一日MA10 ≤ 前两日MA10
```

**适用场景**: 追求信号的时效性，适合短线操作。

```python
def _check_strict_turn_up(self, ma10):
    cur_ma = ma10.iloc[-1]
    prev_ma = ma10.iloc[-2]
    prev2_ma = ma10.iloc[-3]
    
    is_turn_up = (cur_ma > prev_ma) and (prev_ma <= prev2_ma)
    strength = (cur_ma - prev_ma) / prev_ma if prev_ma != 0 else 0
    
    return is_turn_up, strength
```

### 3.2 放宽模式 (relaxed)

**原理**: 允许MA10已经抬头1-4周，提供更宽松的筛选条件。

**判断条件**:
```
最近1-4周内，MA10保持连续上升
```

**适用场景**: 信号更稳定，不要求精确的转折点。

```python
def _check_relaxed_turn_up(self, ma10):
    # 统计连续上升的周数
    turn_up_weeks = 0
    for i in range(1, len(ma10)):
        if ma10.iloc[-i] > ma10.iloc[-i-1]:
            turn_up_weeks += 1
        else:
            break
    
    # 在指定周数范围内
    is_turn_up = (self.min_turn_up_weeks <= turn_up_weeks <= self.max_turn_up_weeks)
    avg_strength = sum(...) / turn_up_weeks if turn_up_weeks > 0 else 0
    
    return is_turn_up, avg_strength, turn_up_weeks
```

### 3.3 趋势模式 (trend)

**原理**: MA10呈现整体向上趋势，不要求连续上升。

**判断方法**:
1. 使用线性回归计算MA10整体斜率
2. 检查最近3周是否有加速度

**适用场景**: 捕捉持续性的上涨趋势。

```python
def _check_trend_turn_up(self, ma10):
    # 线性回归斜率
    x = np.arange(len(ma10))
    slope, _ = np.polyfit(x, ma10.values, 1)
    
    is_trend_up = slope > 0
    
    # 计算加速度
    if len(ma10) >= 4:
        recent_slope1 = (ma10.iloc[-1] - ma10.iloc[-2]) / ma10.iloc[-2]
        recent_slope2 = (ma10.iloc[-2] - ma10.iloc[-3]) / ma10.iloc[-3]
        acceleration = recent_slope1 - recent_slope2
    else:
        acceleration = 0
    
    return is_trend_up, slope + acceleration
```

## 4. 综合评分体系

### 4.1 评分维度

| 维度 | 说明 | 权重调整 |
|------|------|----------|
| 抬头强度 | MA10日变化率 | 主导（1000倍放大） |
| 股价位置 | 股价相对MA10偏离度 | 500倍缩放 |
| 趋势稳定性 | MA10变化的波动性 | 200倍缩放 |

### 4.2 抬头强度评分

**计算逻辑**:
```
strength_score = (当前MA10 - 前一日MA10) / 前一日MA10 × 1000
```

**技术意义**:
- 斜率越陡，信号越强
- 例如：MA10从10元涨到10.1元（1%涨幅），得分 = 10分

### 4.3 股价位置评分

**计算逻辑**:
```
position_score = (股价 - MA10) / MA10 × 500
```

**技术意义**:
- 股价在MA10之上越多越好
- 反映股票的强势程度
- 例如：股价12元，MA10=10元，偏离20%，得分 = 100分

### 4.4 趋势稳定性评分

**计算逻辑**:
```python
if len(ma10) >= 5:
    recent_changes = ma10.pct_change().dropna().tail(4)
    stability = 1 - recent_changes.std()  # 波动越小越稳定
    stability_score = stability * 200
```

**技术意义**:
- 平稳上升的MA10比剧烈波动的更可靠
- 过滤虚假信号
- 例如：标准差0.12%，稳定性0.9988，得分≈200分

### 4.5 综合评分公式

```python
total_score = strength_score + position_score + stability_score
```

## 5. 时间衰减机制

### 5.1 指数衰减

```python
def _calculate_time_decay_weight(self, signal_days_ago):
    if not self.time_decay_enabled or signal_days_ago <= 0:
        return 1.0
    
    if self.decay_type == "exponential":
        return 0.5 ** (signal_days_ago / self.decay_half_life)
    elif self.decay_type == "linear":
        max_days = self.decay_half_life * 2
        return max(0, 1 - (signal_days_ago / max_days))
```

### 5.2 动量衰减模型

```python
def momentum_decay_model(initial_momentum, days_ago, decay_factor=0.85):
    """
    动量随时间自然衰减
    """
    if days_ago <= 0:
        return initial_momentum
    
    decayed_momentum = initial_momentum * (decay_factor ** days_ago)
    return decayed_momentum
```

## 11. 注意事项

1. **数据要求**: 需要至少15天数据，不足的股票会被跳过
2. **模式选择**: 
   - 严格模式适合追求时效性的短线操作
   - 放宽模式提供更稳定的信号
   - 趋势模式适合中线持有
3. **时间衰减**: `decay_half_life`控制信号衰减速度，可根据交易周期调整
4. **过滤条件**: 成交量确认和股价位置过滤可提高信号质量
5. **风险控制**: MA10抬头信号可能失败，建议结合止损策略使用
